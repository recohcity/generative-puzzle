# 全新独立项目：“彩色玻璃花窗艺术平台” (Stained Glass Mosaic Art Platform) 构思方案

## 1. 项目定位与核心愿景

**项目名称**：（暂定）*Lumina Mosaic / 圣光花窗*  
**定位**：一款兼具**创作、解谜、收集与社交裂变属性**的沉浸式生成式艺术拼图平台。

打破传统拼图游戏的单局局限，将大教堂彩色玻璃花窗（Stained Glass）的古典艺术美学与生成式几何算法融合。玩家在游戏中不仅是解谜者，更是在组装与收集独一无二的透光艺术品。

---

## 2. 核心玩法模式矩阵 (Mosaic Mode Matrix)

| 模式分类 | 视觉与生成逻辑 | 玩法特点与体验 |
| :--- | :--- | :--- |
| **1. 纯粹随机花窗<br>(Pure Mosaic)** | Voronoi 晶格多边形剖分 + 渐变透光宝石色彩。 | **纯粹解谜**：无固定主体，专注边缘凹凸咬合与色彩梯度推导。 |
| **2. 具象主题花窗<br>(Patterned Mosaic)** | 动态调用第三方开源矢量库（Iconify / Noto Emoji / 几何曼陀罗算法）提取线条。 | **艺术探索**：拼图过程中逐步展现花卉、飞鸟、天体等艺术线条。 |
| **3. 主体 + 随机背景<br>(MosaicHybrid)** | 核心具象主体（如飞鸟/花卉）+ 附属基座（如仙人掌）+ 外部 Voronoi/放射状背景马赛克。 | **层次分明**：主体识别度高，背景充填具备极高挑战性与丰富视觉对比。 |
| **4. 用户自定义上传<br>(Custom Photo Mosaic)** | 用户上传个人照片，通过前端边缘检测 (Sobel Operator) 提取主体，采样真实色彩纹理。 | **个性创作**：将私人宠物、人物、风景照片转化为专属彩色玻璃花窗。 |

---

### 2.1 MosaicHybrid 典型视觉效果与三层分割架构剖析

以经典马赛克作品《仙人掌上的麻雀》为例，`MosaicHybrid` 的生成逻辑划分为 **三层独立剖分与色彩充填 (3-Zone Subdivision Architecture)**：

1. **第一层：前景核心主体 (Primary Subject Zone - 雀鸟)**
   - **分割特征**：沿鸟类的眼睛、喙、羽毛翅纹等矢量关键线进行高密度精细切分。
   - **配色采样**：灰黑、棕褐色系与象牙白，突出鸟类羽毛立体感。
2. **第二层：依托基座主体 (Secondary Subject Zone - 仙人掌)**
   - **分割特征**：沿圆形仙人掌轮廓呈**网格/同心圆环状 (Grid/Concentric Ring Cut)** 切分，并在节点处保留刺孔细节（黄点）。
   - **配色采样**：橄榄绿与墨绿渐变。
3. **第三层：背景填充区 (Background Zone - 橙红马赛克墙面)**
   - **分割特征**：以主体外轮廓线为阻断边界，向外呈**环状扩展的 Voronoi / 抖动马赛克晶格**。
   - **配色采样**：高饱和度橙红/暖珊瑚色，与青绿/棕灰的主体形成强烈色彩对比。

## 3. 长局保护与沉浸式体验机制

针对 50 - 200 片的高难度马赛克长局拼图，设计完整的保护与辅助支撑体系：

### 3.1 自动存档与断点续玩 Engine
- 使用 `IndexedDB` 增量实时保存：当前拼图坐标、旋转角、已锁定碎片、累积用时。
- 用户意外关闭网页或微信后再次进入，自动弹出恢复提示：“检测到未完成的《马赛克花窗》(完成度 65%)，是否继续？”

### 3.2 辅助与提示系统 (Assistive Features)
- **半透明鬼影轮廓 (Ghost Overlay)**：长按提示显示原图暗色投影与铅线参考线。
- **铅条磁吸感 (Lead Line Magnetism)**：碎片接近正确槽位与角度时（$\Delta xy < 15\text{px}, \Delta\theta < 10^\circ$），触发微震动反馈并自动吸附嵌入。
- **碎片分类托盘 (Piece Drawer)**：支持按色调（如红宝石色系、靛青色系）快速分类。

### 3.3 个人花窗画廊 (Personal Stained Glass Gallery)
- 每完成一幅拼图，即可将其陈列于个人虚拟画廊（具有大教堂透光陈列墙视觉）。
- 支持**【刷新纪录/二刷挑战】**：保持相同切割线条重新打乱，挑战个人最快解题记录。

---

## 4. 社交裂变与传播机制 (Viral Growth Engine)

### 4.1 拼图过程时光回放 (Timelapse Replay) 🌟
- 自动增量记录每一步有效拼接动作。
- 拼图完成时，生成 **10 秒快进动画（GIF / 短视频）**，流畅展现玻璃碎片从漫天散落到完美聚合成花窗的全过程，极具小红书/抖音传播价值。

### 4.2 拼图种子与好友 PK 挑战 (Mosaic Seed Challenge)
- 玩家可将其自定义或生成的拼图打包为**“挑战卡片 / 微信小程序码”**。
- 好友点击链接后，在**完全相同的分割线与图片**下进行异步比拼，排行榜实时对比“通关用时”与“旋转效率”。

### 4.3 高清艺术海报导出 (2K/4K Poster Export)
- 拼图通关触发“终局圣光绽放 (Completion Bloom Effect)”特效。
- 离屏渲染 `2K/4K` 高清图像，叠加大理石/黑铅质感、通关日期、艺术签名与名言，支持一键保存分享。

---

## 5. 推荐技术选型与架构设计

1. **渲染层**：
   - 使用 WebGL / Three.js 材质 Shader 实现真实玻璃透光、微小气泡纹理与黑铅缝（Lead Came Lines）的高光反射。
2. **计算层**：
   - 采用 Web Workers 处理复杂的多边形剖分 (Voronoi/Delaunay) 与图像边缘检测，确保主 UI 线程维持 60FPS。
3. **云端与存储**：
   - 前端基于 Next.js + React 19。
   - 存储使用 IndexedDB（本地长局存档）+ Supabase（云端画廊、好友挑战种子榜单与图片 Storage）。
