# 多端自适应适配规范（已验证体系）

本项目多端适配的攻关成果沉淀。任何涉及布局、尺寸、交互的新增/修改，按本文档三端核对。

## 设备分型（单一权威）

`getDeviceType()` 统一返回四种形态，组件层不得重复实现设备判断：

| 形态 | 判定要点 | 布局特征 |
| --- | --- | --- |
| `desktop` | 桌面宽屏 | 双栏：左画布 + 右面板 |
| `mobile-portrait` | 手机竖屏 | 单栏：画布为主、面板收敛/折叠 |
| `mobile-landscape` | 手机横屏 | 画布居中、面板极简 |
| `ipad` | 平板 | 双栏但面板更宽、触控目标加大 |

## 自适应缩放体系

- 全局面板尺寸由 `--panel-scale` CSS 变量驱动（各断点归一化），按钮高、字号、间距统一乘该系数，禁止逐组件硬编码像素。
- 画布自适应由 `constants/canvasAdaptation.ts` + `utils/rendering/CanvasAdapter.ts` 负责；`RESET_GAME` 保留 `canvasSize`/`baseCanvasSize` 防布局抖动。
- 刘海屏：Safari iPhone 左右不对称已专门处理，底部安全区采用"岛屿防御"（safe-area-inset 兜底），改动时不得破坏该修复。
- 浏览器目标：Chrome / Safari / 微信内置浏览器三端一致。

## 信息密度取舍（移动端）

- 移动端隐藏次要标题（如"选择切割类型"小标题），释放空间防止按钮溢出不可点。
- 窄屏下功能收敛为 tab（如"难度 / 切割"两 tab），不堆多列。
- 按钮最小触控目标 44×44px（桌面可 32px）；溢出时允许换行/收缩字号，禁止超出画布。

## 几何层 × 端能力联动（易踩坑）

- 碎片可拾取性受端能力约束：桌面鼠标可精确点击极小碎片；触控（手机/iPad）要求碎片面积下限更高。
- 几何层约束：增量切割器 `MIN_AREA_RATIO = 0.004`（碎片 ≥ 总形状 0.4%）是**全局下限**，与端无关；规则网格类（蜂巢）在低难度会产生大量极小碎片，需按面积比例合并（<25% 单元面积并入相邻块）或限制难度，否则触控端几乎不可操作。
- 新增切割类型时必须显式评估"低难度 × 小碎片"的端差异，不能只保证桌面端可玩。

## 三端验证清单（封板硬门槛）

> **封板硬门槛（2026-09-19 起强制）**：涉及布局/渲染/切割/交互的任何版本，**必须真实手机实测通过才能封板推送**。
> 教训（1.5.6-1.5.13）：切割架构桌面端全部正常，但移动端交互问题严重（Worker 冷启数秒、连点排队阻塞、纹理创建放大 3-5 倍、iPad 橡皮筋拖动面板、滑块 touch 卡顿）——桌面测试通过 ≠ 移动端可交付。1.5.14 深度测试才集中修复。

封板前逐项实测（**真实设备优先**；无法真实设备时用浏览器移动视口 + 合成 TouchEvent 等效）：

1. 桌面（Chrome 宽屏）：双栏布局、hover 态、鼠标拖拽/滚轮旋转、按钮无溢出。
2. 移动竖屏 + 横屏（Safari / 微信内置）：单栏收敛、tab 可用、44px 触控目标、安全区无遮挡、碎片可拖起可旋转。
3. 平板（iPad 横屏 + 竖屏）：双栏、触控目标加宽、面板不可被拖动、多指手势（若启用）。
4. 每端跑一遍完整游戏流程：生成 → 切割 → 散开 → 拖拽/旋转 → 完成结算，确保面板与画布均可达。
5. **切割响应**（1.5.14 回归重点）：10 种切割类型逐一点击，确认首帧显示速度、连点/切换不被阻塞、拖拽无闪烁。

## 移动端专属问题速查（1.5.14 修复清单，新增改动不得回退）

| 问题 | 根因 | 1.5.14 解法（不得回退） |
| --- | --- | --- |
| 首次切割数秒等待 | Worker 冷启 + 每次重建 | 页面加载预创建 + 忙闲复用 |
| 连点/切换被阻塞 | 单 Worker 串行队列 | 请求抢占（旧切割立即中断，CUT_SUPERSEDED_ERROR 静默） |
| 嵌齿/放射慢 | 大/复杂碎片纹理创建 + 放射平面图求交 | 放射顺序分割 + 纹理 DPR cap 1 + 尺寸 cap 256px |
| 切割后闪烁 | 快显与纹理版视觉突变 | 快显方案已回退，保持单次同步渲染 |
| iPad 横屏面板可拖动 | iOS Safari 橡皮筋弹动（pan-x/pan-y） | desktop 布局整层 touch-action: none |
| 难度滑条卡顿/无吸附 | 原生 range touch 行为不一致 | 8 点位专业滑条（吸附、逐点音效、端点对齐） |
